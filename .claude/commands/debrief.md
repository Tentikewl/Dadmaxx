# /debrief — End-of-Day Quick Check-In

Fast. 2 minutes max. Ryan is tired.

## Ask at most 3 questions

Ask them together, not one at a time:

1. How did today go overall?
2. What did Harry eat / how was formula?
3. How were naps?

If Ryan volunteers extra info (activities, a development moment, a fussy stretch) — capture it. Don't ignore it just because it wasn't asked.

## After Ryan responds — write immediately

Route everything to the right file:

- Food / formula mentions → `logs/feeds.md`
- Sleep / nap mentions → `logs/sleep.md`
- Activity mentions → `logs/activities.md`
- Development observations → `logs/milestones.md`

Also update supporting files if relevant:
- `food-tracker.md` — if a new food was tried or reaction noted
- `activity-tracker.md` — if an activity was attended

Always write one line to `logs/sessions.md` (newest first):
```
2026-05-03: /debrief — good day, solids decent, naps ok.
```

## Response after writing

Reply with exactly:
- "Logged." + one sentence summary of the day
- One optional tomorrow flag if something worth flagging (short nap, skipped feed, etc.)
- Nothing else

Example:
> Logged. Good day — Harry smashed the avocado and naps were solid.
> Tomorrow flag: Nap 1 was short — might need an earlier window.

## Tone

Warm, brief. Ryan doesn't need to read paragraphs at the end of the day.
