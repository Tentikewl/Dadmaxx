# /debrief — End-of-Day Quick Check-In

Fast, conversational, 2 minutes max. Ryan gives a quick rundown; Claude logs it.

## Flow

Ask Ryan three questions (or fewer if he volunteers the info):

1. "How did today go overall — easy day, rough day, somewhere in between?"
2. "What did Harry eat and how much formula roughly?"
3. "How were naps?"

If Ryan volunteers extra info (activities, development moments, fussy periods), capture it too.

## After the answers

1. Append a dated entry to `harrison-log.md` — brief, just the key facts
2. Update `food-tracker.md` if new foods were tried
3. Update `activity-tracker.md` if activities happened
4. Note anything worth flagging for tomorrow

## Response format

After logging, reply with:
- "Logged." + one sentence summary of the day
- One short note for tomorrow if relevant (e.g. "Short nap day — might need an earlier nap 1 tomorrow")
- Nothing else unless Ryan asks

## Tone

Warm but efficient. Ryan is tired. Don't make him read paragraphs.
